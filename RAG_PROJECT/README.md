# 🎥 Video Course RAG Assistant

A Retrieval-Augmented Generation (RAG) system that lets you ask natural-language questions about a video course and get back an answer **plus the exact video, timestamp, and clip to watch** — built on top of Whisper transcription, local embeddings, FAISS vector search, and Gemini.

---

## How It Works

```
VIDEOS (.mp4)
   │  process_video.py  (ffmpeg: extract audio)
   ▼
AUDIOS (.mp3)
   │  create_chunks.py  (Whisper: transcribe + timestamp segments)
   ▼
jsons/  (raw per-segment transcripts with timestamps)
   │  merge_chunks.py  (group small segments into larger, coherent chunks)
   ▼
new_json/  (merged chunks, ready for embedding)
   │  read_chunks.py   (embed each chunk, build FAISS index)
   ▼
output2.csv  +  course.index
   │  process_incoming.py  (embed query, FAISS search, ask Gemini)
   ▼
Answer with video number, title, and timestamp
```

## Features

- **Multi-video semantic search** — ask about any topic across your entire video library
- **Multi-topic questions** — "explain X and Y" is automatically split and answered per topic
- **Timestamp-accurate retrieval** — answers point to the exact video + second range where a topic was taught
- **FAISS vector search** — scalable similarity search instead of brute-force cosine similarity
- **Local embeddings** — uses a locally-hosted `bge-m3` model via Ollama (no per-query embedding API cost)

## Project Structure

```
├── process_video.py       # Step 1: extract audio from video files (ffmpeg)
├── create_chunks.py       # Step 2: transcribe audio with Whisper, save timestamped segments
├── merge_chunks.py        # Step 3: group small segments into larger coherent chunks
├── read_chunks.py         # Step 4: embed chunks, build FAISS index (run once / when new videos added)
├── process_incoming.py    # Step 5: query the index, get an answer with timestamps
├── Embeddings.py           # Shared embedding helper (calls local Ollama endpoint)
├── stt.py                  # Standalone Whisper test script
├── requirements.txt
├── .env.example             # Template — copy to .env and add your real key
└── .gitignore
```

## Setup

**1. Install dependencies**
```bash
pip install -r requirements.txt
```

**2. Install and run Ollama with the embedding model**
```bash
ollama pull bge-m3
ollama serve
```

**3. Set up your API key**
```bash
cp .env.example .env
```
Edit `.env` and add your real Gemini API key:
```
GEMINI_API_KEY=your_actual_key_here
```
Get a key at [Google AI Studio](https://aistudio.google.com/apikey).

**4. Add your videos**

Place `.mp4` files in a `VIDEOS/` folder.

## Running the Pipeline

Run these once, in order, whenever you add new videos:

```bash
python process_video.py     # VIDEOS/ -> AUDIOS/
python create_chunks.py     # AUDIOS/ -> jsons/ (Whisper transcription)
python merge_chunks.py      # jsons/ -> new_json/ (chunk merging)
python read_chunks.py       # new_json/ -> output2.csv + course.index (embeddings + FAISS)
```

Then, ask questions anytime:

```bash
python process_incoming.py
```

## Notes & Limitations

- Embeddings run locally via Ollama (`bge-m3`), so no external embedding API costs, but requires Ollama running locally
- Whisper's `large-v2` model is used for transcription — accurate but slow on CPU; a GPU is strongly recommended
- The FAISS index (`course.index`) and `output2.csv` are regenerated by `read_chunks.py` — they are not committed to this repo (see `.gitignore`) since they're derived data, not source
- Answers are strictly grounded in retrieved course chunks — the prompt explicitly instructs the model not to write code or explain implementation, only point to where a topic is covered

## Tech Stack

- **Whisper (large-v2)** — speech-to-text transcription
- **Ollama + bge-m3** — local text embeddings
- **FAISS** — vector similarity search
- **Gemini 2.5 Flash** — answer generation
- **pandas / numpy** — data handling
